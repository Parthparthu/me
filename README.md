## 🌌 Overview & Philosophy

</div>

> *"Building software from first principles — understanding how bits flow through protocols, how graphics compute in parallel on the GPU, while obsessing over client performance, fluid micro-interactions, and pristine accessibility."*

This repository houses **Pradyumna's v2.0 Developer Portfolio** — a production-grade, spatial web experience engineered with **Next.js 15 (App Router & Turbopack)**, **React 19**, **Three.js / React Three Fiber**, and **Tailwind CSS**.

Far more than a simple showcase, it functions as a **living technical benchmark**: featuring a 3D spatial multi-room canvas, custom SVG liquid glass displacement shaders, adaptive GPU tier scaling, a hardware-accelerated magnetic cursor, a global keyboard command palette (`Cmd + K`), an interactive secret Konami code Easter Egg, dynamic case study routes (`/projects/[slug]`), a live Design System Showroom (`/design-board`), and an Edge-compatible contact dispatch pipeline powered by **Resend** and **Zod**.

### 🔄 Hydration & Runtime Lifecycle

```mermaid
sequenceDiagram
    autonumber
    actor User as 👤 Visitor
    participant Browser as 🌐 Client Browser
    participant Layout as ⚙️ Next.js RootLayout
    participant Lenis as 🌊 Lenis Scroll
    participant WebGL as 🌌 Three.js SceneCanvas
    participant View as 🖥️ Page Component

    User->>Browser: Requests URL (e.g. /)
    Browser->>Layout: Ingests HTML & Google Variable Fonts (Inter, Space Grotesk)
    Layout->>Layout: Resolves Theme Preference (dark/light)
    Layout->>Lenis: Mounts SmoothScrollProvider & initiates RAF loop
    Layout->>WebGL: Mounts SceneCanvas with CameraRig (SSR: false)
    WebGL->>WebGL: Assesses GPU Tier (useSceneStore) & builds 3D Rooms
    Layout->>View: Hydrates HomePage sections with Framer Motion triggers
    User->>Browser: Moves mouse / scrolls page
    Browser->>WebGL: CameraRig smoothly transitions camera coordinates between Rooms
    Browser->>Lenis: Interpolates scroll offset for smooth camera & parallax
```

### 🧪 Liquid Glass Refraction & Shader Architecture

The `LiquidGlass` system creates physical depth without standard heavyweight shaders:
1. **SVG Displacement Map**: `GlassSVGFilter.tsx` defines an SVG filter `<feTurbulence type="fractalNoise">` feeding into `<feDisplacementMap>` to simulate micro-imperfections in polished glass.
2. **Backdrop Blur & Dual Border**: Uses modern `backdrop-filter: blur(16px)` combined with semi-transparent specular edges (`rgba(255, 255, 255, 0.16)`).
3. **Dynamic Elevation Tiers**: Supports 5 elevation levels scaling shadow spread and refraction index.
4. **Hardware Adaptation**: Automatically scales back to simplified CSS opacity when `QualityToggle` is set to Low or Off.

### 📬 Type-Safe Contact Pipeline Sequence

```mermaid
sequenceDiagram
    autonumber
    actor Visitor as 👤 Visitor
    participant Form as 📝 ContactForm (React Hook Form)
    participant Zod as 🛡️ Zod Validation
    participant Route as ⚡ POST /api/contact
    participant Resend as ✉️ Resend API

    Visitor->>Form: Enters Name, Email & Message

    Form->>Zod: Validates client inputs against contactSchema
    alt Validation Fails
        Zod-->>Form: Returns formatted inline field errors
        Form-->>Visitor: Displays input feedback & focuses invalid field
    else Validation Passes
        Form->>Route: Dispatches JSON payload
        Route->>Zod: Re-validates server-side payload
        Route->>Resend: Dispatches email transaction with HTML template
        Resend-->>Route: 200 OK (Email Queued)
        Route-->>Form: { success: true }
        Form-->>Visitor: Renders celebratory confirmation toast & resets form
    end
```

## 🚀 How To Use: Step-by-Step Guide

</div>

### 📋 Prerequisites

Ensure your environment satisfies the following minimum runtime requirements:

| Tool | Required Version | Recommended | Verification Command |
|:---|:---:|:---:|:---|
| **Node.js** | `>= 18.18.0` | `v20.x LTS` or `v22.x` | `node -v` |
| **pnpm** (preferred) | `>= 8.x` | `pnpm v9+` | `pnpm -v` |
| **npm** (fallback) | `>= 9.x` | `npm v10+` | `npm -v` |

---

### ⚡ Quickstart (One-Liner)

```bash
git clone https://github.com/Parthparthu/Portfolio.git && cd Portfolio && pnpm install && pnpm dev
```

---

### 1️⃣ Clone the Repository

```bash
# Clone via HTTPS
git clone https://github.com/Parthparthu/Portfolio.git

# Navigate into project directory
cd Portfolio
```

---

### 2️⃣ Install Dependencies

Using **pnpm** (recommended for speed and disk-space optimization):

```bash
pnpm install
```

*Or using npm:*
```bash
npm install
```

---

### 3️⃣ Configure Environment Variables

Create your local environment file by copying the template:

```bash
# On Linux / macOS / Git Bash
cp .env.example .env.local

# On Windows PowerShell
Copy-Item .env.example .env.local
```

Open `.env.local` in your editor and configure:

```env
# ==============================================================================
# PRADYUMNA DEVELOPER PORTFOLIO - LOCAL ENVIRONMENT CONFIG
# ==============================================================================

# Resend API Key for contact form mail delivery (Get one at https://resend.com)
# (Leave blank in development to test UI without sending real emails)
RESEND_API_KEY=re_your_api_key_here

# Recipient email where contact form submissions will be delivered
CONTACT_EMAIL=your-email@example.com

# Public Site URL for canonical meta tags & OpenGraph preview cards
NEXT_PUBLIC_SITE_URL=http://localhost:3000

# Optional GitHub Personal Access Token to raise rate limits from 60 to 5000 req/hr
GITHUB_TOKEN=
```

---

### 4️⃣ Launch Development Server (with Turbopack)

Start the high-speed Turbopack development server:

```bash
pnpm dev
```

> ⚡ Turbopack compiles pages on-demand in milliseconds! Open your browser and navigate to:
> **`http://localhost:3000`**

---

### 5️⃣ Quality Verification & Type Checking

Verify that all TypeScript code passes strict mode checks without compilation errors:

```bash
# Run TypeScript compilation check
pnpm typecheck

# Run Next.js linting checks
pnpm lint
```

---

### 6️⃣ Build & Run for Production

Compile optimized production server bundles and test locally:

```bash
# Build optimized Next.js production bundle
pnpm build

# Start local production server
pnpm start
```

---

### 7️⃣ Deployment Guidelines

#### Deploying to **Vercel** (Recommended)
1. Push your repository to GitHub.
2. Visit [Vercel Dashboard](https://vercel.com/new) and import `Portfolio`.
3. Set Framework Preset to **Next.js**.
4. In **Environment Variables**, add:
   - `RESEND_API_KEY`
   - `CONTACT_EMAIL`
   - `NEXT_PUBLIC_SITE_URL`
5. Click **Deploy**. Vercel will build and assign your production domain.

#### Deploying via **Docker / Self-Hosted**
Build a standalone container using Node.js:
```dockerfile
FROM node:20-alpine AS runner
WORKDIR /app
COPY . .
RUN npm install -g pnpm && pnpm install --frozen-lockfile
RUN pnpm build
EXPOSE 3000
CMD ["pnpm", "start"]
```

## ❓ Frequently Asked Questions (FAQ)

</div>

<details>
<summary><b>🔍 How does the contact form work without a traditional backend server?</b></summary>
<br/>
The contact form submits directly to the Next.js 15 Edge-compatible Route Handler at <code>app/api/contact/route.ts</code>. The payload is first validated by <b>Zod</b> schemas on both client and server. If valid, it dispatches an email via the <b>Resend</b> API. In local environments where no <code>RESEND_API_KEY</code> is configured, the route logs the submission to the terminal and returns a successful response so the frontend flow can be tested without errors.
</details>

<details>
<summary><b>🎨 Can I customize the neon color scheme?</b></summary>
<br/>
Yes! All brand and accent colors are configured as CSS custom variables in <code>app/globals.css</code> (e.g. <code>--brand-cobalt</code>, <code>--brand-cyan</code>, <code>--accent-primary</code>, <code>--accent-emerald</code>) and mapped directly into <code>tailwind.config.ts</code>. Modifying these tokens instantly updates the entire UI across dark and light modes.
</details>

<details>
<summary><b>📱 How does the GPU Quality Tier system work?</b></summary>
<br/>
The portfolio features an adaptive GPU tier management system built into <code>store/useSceneStore.ts</code> and exposed via <code>QualityToggle.tsx</code>. It detects device capabilities and lets users manually toggle between:
<ul>
  <li><b>High</b>: Full 3D multi-room canvas, post-processing shaders, bloom & particle dust.</li>
  <li><b>Medium</b>: Simplified 3D geometry without post-processing.</li>
  <li><b>Low</b>: Pure CSS liquid glass without WebGL rendering.</li>
  <li><b>Off</b>: Completely static view with zero animations for battery saving.</li>
</ul>
</details>
