# Tasks Directory — Ralph PRDs

This directory stores Product Requirements Documents (PRDs) generated by the `/prd` skill.

## Workflow

1. **Generate PRD**:
   ```text
   /prd [feature description]
   ```
   Answers are gathered interactively and the result is saved as `tasks/prd-[feature-name].md`.

2. **Convert to `prd.json`**:
   ```text
   /ralph tasks/prd-[feature-name].md
   ```
   This generates or updates `prd.json` in the project root with atomic, dependency-ordered user stories.

3. **Run Ralph**:
   ```powershell
   npm run ralph
   ```
